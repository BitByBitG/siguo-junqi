# 四国军棋

一个供 2～4 名真人在线游玩的四国军棋网页。服务端负责规则判定和暗棋信息隔离，房间数据暂存在内存中。

## 运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm start
```

浏览器打开 `http://localhost:3000`。

## 通过 VS Code Tunnel 分享

1. 在 VS Code 的“端口”面板中转发端口 `3000`。
2. 将该端口的可见性改为 `Public`。
3. 把生成的 HTTPS 地址发给其他玩家。

服务器进程和 VS Code Tunnel 必须保持运行。重启服务器会清空所有房间。

## 玩法

- 2 人房间使用南、北两个相对阵营。
- 3 人房间使用北、东、南三个阵营。
- 4 人房间可选择混战或对家结盟（南北一队，东西一队）。
- 玩家进入后可点击两枚己方棋子交换位置，准备后由房主开局。
- 工兵可以在连通的铁路上转弯，其他可移动棋子只能沿直线铁路行进。
- 中央保留九个铁路点，组成三条南北直道和三条东西直道；工兵可在点上转向，其他棋子只能直行，相对阵营的第 1、3、5 列分别对穿。
- 每方第三行第三列的中央行营只接公路，不与铁路相连。
- 每方左侧纵向铁路与左侧相邻阵营的下侧铁路通过唯一角点弯道相接；这条折线按直道处理，普通棋子也能沿线通过，但不能越过阻挡。
- 最后一行只通过普通道路连接倒数第二行，不接铁路。
- 隐蔽模式会压暗界面，并将四方改为灰色、棕色、深绿色、深蓝色；敌方暗棋背面不显示文字。
- 行营中的棋子不能被攻击；大本营中的棋子不能移动。
- 司令阵亡后，同阵营军旗会公开。

该项目用于朋友间联机游玩，没有账号系统和持久化数据库。
